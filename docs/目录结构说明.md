# 目录结构说明

## 本仓库（jianji-android · Android 端）

```
jianji-android/
├── src/                        # 前端（纯 HTML/CSS/JS，无打包器）
│   ├── index.html              # App Shell：首页/明细/统计/我的 + 全部弹层
│   ├── styles.css              # 设计系统：浅/深 token、组件、动效、安全区
│   ├── core.js                 # 纯函数核心：分类、金额、汇总、关键词归类（window.JJ）
│   ├── app.js                  # 状态、渲染、交互、localStorage 持久化
│   └── assets/icons/           # 分类线性图标（复用小程序 assets/icons）
├── src-tauri/
│   ├── src/main.rs             # Android 入口，调用 lib.rs::run()
│   ├── src/lib.rs              # 共享 Tauri Builder
│   ├── gen/                    # `tauri android init` 生成（gitignore，不入库）
│   ├── icons/                  # 应用图标：标准尺寸 + android/mipmap-*
│   ├── build.rs                # Tauri 构建脚本
│   ├── Cargo.toml              # tauri 2 / serde；dev profile 剥离符号
│   └── tauri.conf.json         # 标识 com.yu06118.jianji，版本 0.1.1，前端指向 ../src
├── .github/workflows/android.yml   # CI：构建 debug APK（arm64，按 ABI 拆分）
├── shared/                     # 跨端共享逻辑占位（分类/汇总口径与桌面端对齐）
├── docs/
│   ├── 目录结构说明.md          # 本文件
│   └── Android构建指南.md       # 环境、CI/本地构建、签名、调试、排错
├── package.json                # @tauri-apps/cli 与 npm 脚本
├── package-lock.json
├── .gitignore                  # 排除 node_modules、target、gen、apk、keystore
└── README.md                   # 功能、设计语言、下载与构建入口
```

### 前端分层

| 层 | 文件 | 职责 |
|----|------|------|
| 设计系统 | `styles.css` | 浅/深双套 token、圆角分级、280ms 缓动、组件与弹层 |
| 领域核心 | `core.js` | 17 个分类、金额分单位换算、月度汇总、按日分组、关键词自动归类 |
| 应用层 | `app.js` | 四视图渲染、记账/明细/统计/设置交互、localStorage、备份导入 |
| 壳 | `index.html` | 静态结构，类名与 `styles.css` 一一对应 |

## 仓库拆分总览（重构后）

| 仓库 | 承载内容 | 目录要点 |
|------|---------|---------|
| `jianji` | 文档总导航 | 四端文档集合与直达入口，不存放业务代码 |
| `jianji-miniprogram` | 微信小程序端（主端） | `app.js/app.json` 全局配置、`pages/` 页面、`utils/` 工具、`assets/` 静态资源、发布与测试文档 |
| `jianji-windows` | Windows 桌面端 | `desktop/` Tauri v2 工程、`shared/` 共享逻辑、`docs/`、`prototypes/` 设计稿 |
| `jianji-macos` | macOS 桌面端 | 与 desktop 同构：`desktop/` + `shared/` + `docs/`，面向 Intel 与 Apple Silicon |
| `jianji-android`（本仓库） | Android 端（APK） | `src/` 前端 + `src-tauri/` Tauri v2 移动端 + `.github` CI；v0.1.1 debug APK |
