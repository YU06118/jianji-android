# 目录结构说明

## 本仓库（jianji-android · Android 端）

```
jianji-android/
├── src/                     # 前端界面（当前为占位 index.html，待移植桌面端 UI）
├── src-tauri/
│   ├── src/main.rs          # Android 入口，调用 lib.rs::run()
│   ├── src/lib.rs           # 共享 Tauri Builder，后续注册记账核心命令
│   ├── gen/                 # `tauri android init` 生成的 Android 工程（gitignore，不入库）
│   ├── icons/               # 应用图标（待补充，需各分辨率 PNG）
│   ├── build.rs             # Tauri 构建脚本
│   ├── Cargo.toml           # Rust 依赖：tauri 2 / serde
│   └── tauri.conf.json      # 应用标识 com.yu06118.jianji，前端产物指向 ../src
├── shared/                  # 跨平台共享逻辑占位（与桌面端仓库同步演进）
├── docs/
│   ├── 目录结构说明.md       # 本文件
│   └── Android构建指南.md   # APK 打包步骤与签名说明
├── package.json             # Tauri CLI 脚本：android:init / android:dev / android:build
├── .gitignore               # 排除 target/、gen/、apk、keystore
└── README.md                # 仓库总览与功能一致性基线
```

## 仓库拆分总览（重构后）

| 仓库 | 承载内容 | 目录要点 |
|------|---------|---------|
| `jianji` | 文档总导航 | 四端文档集合与直达入口，不存放业务代码 |
| `jianji-miniprogram` | 微信小程序端（主端） | `app.js/app.json` 全局配置、`pages/` 页面、`utils/` 工具、`assets/` 静态资源、发布与测试文档 |
| `jianji-windows` | Windows 桌面端 | `desktop/` Tauri v2 工程、`shared/` 共享逻辑、`docs/`、`prototypes/` 设计稿 |
| `jianji-macos` | macOS 桌面端 | 与 desktop 同构：`desktop/` + `shared/` + `docs/`，面向 Intel 与 Apple Silicon |
| `jianji-android`（本仓库） | Android 端（APK） | `src-tauri/` + `src/`，Tauri v2 移动端骨架，内容暂留空 |
